#+TITLE: Code architecture

* Module table
Matches the code as built for [[file:features/queue-based-bind.org][queue-based bind]] (implemented).

| Module | Role | Notes |
|--------+------+-------|
| =freer-monad.rkt= | Core of the library: =pure=, =impure=, =perform=, =return=, =>>== (the exported name of the internal =bind=), =run=, =do-m=, =sequence=, =map-m= | Pure. =impure= has three fields: description, continuation, queue. Exports only =pure=, =impure=, =free?=, =return=, =perform=, =run=, =>>==, =do-m=, =sequence=, =map-m=. Internal: =leaf= and =node= (queue structures, opaque), =bind=, =make-impure=, =resume=, =q-append=, =q-pop= |
| =try-catch.rkt= | =try= and =catch= on the failure effect | Pure. =catch= builds its waiting clause with =perform= and =>>== |
| =effects/*.rkt= | One module per effect: its description, its constructor, and its tests | Pure. Each builds effects with =perform= |

* Data flow
- =perform= creates a waiting computation with one pending continuation, =return=.
- =>>== (=bind=) on a waiting computation appends the function to its queue in O(1). It never wraps the continuation.
- A handler receives the description and the continuation =k=, and may call =k= any number of times.
- Calling =k= resumes the queue (=resume=): it pops functions (=q-pop=) and applies them, and stops at the next waiting computation, whose queue is joined to the rest.
- =run= drives this loop until a pure value is returned.

* Effects
None. The library performs no effects and holds no state. Handlers are supplied by callers.
