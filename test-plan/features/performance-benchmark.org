#+TITLE: Performance benchmark harness: test plan

Test plan for the harness in =benchmark/=; 222 cases: 213 rackunit cases in the (module+ test) block of the module that defines the procedure (the 2 module-level cases in =benchmark/run.rkt=), and 9 shell-level checks (not rackunit) in the last group. Allocation verification and errortrace detection are not planned (dropped by decision). Names below are the procedure; the test name is "<procedure>: should <expected> when <condition>".

Fixture (defined once per file, in its test block):
- Summaries are built with =(summarise '(...))= or by hand with the record fields =median=, =min=, =max=, =iqr=. A "summary with median m, iqr i" is any record with those values.
- =fake-case id variant sizes=: a =bench-case= whose monadic and plain builders return a thunk giving n; ops is identity; equal? is =equal?=. =unequal-case= is the same with plain giving n+1. =counting-sink= is a log sink that counts and stores messages.
- File-system cases run inside =(make-temporary-directory)= with =current-output-root= parameterized to it, delete it afterwards, and compare a snapshot of =research/data/= before and after to show the repository was untouched.
- Log-printing code runs inside =(parameterize ([current-output-port (open-output-nowhere)]) ...)= except where silence is the thing checked.
- "Smallest size" is 64; a pair is checked with =case-check= on a copy of the case whose sizes are cut to the first one.
- "raises" means =exn:fail= (or a subtype) unless stated.
