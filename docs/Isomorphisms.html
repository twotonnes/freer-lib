6 Isomorphisms🔗

 (require freer-lib/iso/main) package: freer-lib

An isomorphism (or iso) is a pair of conversion procedures between two representations of the same data, where each procedure is the inverse of the other.

struct

(struct iso (to-proc from-proc))

  to-proc : (-> any/c any/c)
  from-proc : (-> any/c any/c)
An isomorphism between two representations.

  • to-proc: Converts from the source representation to the target representation.

  • from-proc: Converts from the target representation back to the source representation.

Example:
> (define string<->number
    (iso string->number number->string))

procedure

(iso-to i d) → any/c

  i : iso?
  d : any/c
Converts d to the target representation using the to-proc of i.

Example:
> (iso-to string<->number "42")

42

procedure

(iso-from i d) → any/c

  i : iso?
  d : any/c
Converts d back to the source representation using the from-proc of i.

Example:
> (iso-from string<->number 42)

"42"

procedure

(iso->lens i) → lens?

  i : iso?
Converts i to a lens that views a structure in the source representation as its target representation. Setting a value through the lens ignores the original structure and returns the new value converted back with the from-proc of i.

Examples:
> (define number-lens (iso->lens string<->number))
> (view-l number-lens "42")

42
