4 JSON🔗

 (require freer-lib/json/main) package: freer-lib

This module provides helpers for working with JSON inside effectful computations.

procedure

(string->free-jsexpr str log-level) → free?

  str : string?
  log-level : (or/c 'dbg 'inf 'err)
Parses str as JSON with string->jsexpr and returns the resulting jsexpr? as a computation.

If str cannot be parsed, no exception is raised. Instead, the computation logs a message describing the error and the offending string, using log-dbg, log-inf or log-err depending on log-level, and then performs abort. The handler therefore needs to handle both log-effect and abort-effect.

Examples:
> (define (handler eff k)
    (match eff
      [(log-effect level msg) (k (void))]
      [(? abort-effect?) (return 'aborted)]))
> (run (string->free-jsexpr "{\"name\": \"Alice\", \"age\": 30}" 'err) handler)

'#hasheq((age . 30) (name . "Alice"))

> (run (string->free-jsexpr "{not json" 'err) handler)

'aborted
