5 Lenses🔗

 (require freer-lib/lens/main) package: freer-lib

This section documents the lens system — a composable, purely functional approach to focusing on and updating values inside nested data structures. The freer-lib/lens/main module re-exports all of the modules described below.

5.1 🔗

5.1.1 Core Lens🔗

 (require freer-lib/lens/lens) package: freer-lib

This module provides the core lens abstraction — a composable pair of get and set functions that enables focused, immutable access into nested data structures.

struct

(struct lens (get set)
    #:transparent)
  get : (-> any/c any/c)
  set : (-> any/c any/c any/c)
A first-class lens value pairing a getter and a setter.

  • get: A procedure that takes a structure and extracts the focused value from it.

  • set: A procedure that takes a new value and a structure (in that order) and returns a new structure with the focused value replaced.

Lenses are expected to obey the usual lens laws: viewing after setting returns the value that was set, setting the value that was just viewed returns an equal structure, and setting twice is the same as setting once with the last value.

Examples:
> (define first-lens
    (lens first
          (lambda (new-v lst) (list-set lst 0 new-v))))
> first-lens

(lens #<procedure:first> #<procedure>)

procedure

(view-l l structure) → any/c

  l : lens?
  structure : any/c
Extracts the focused value from structure using the lens l.

Example:
> (view-l first-lens '(10 20 30))

10

procedure

(set-l l new-value structure) → any/c

  l : lens?
  new-value : any/c
  structure : any/c
Returns a new structure with the focused position updated to new-value.

Example:
> (set-l first-lens 99 '(10 20 30))

'(99 20 30)

syntax

(set-l* structure [l new-v] ...)

A syntactic shorthand for chaining multiple set-l operations on a single structure. Each [l new-v] clause is applied left-to-right. Returns structure unchanged when no clauses are provided.

Examples:
> (define second-lens
    (lens second
          (lambda (new-v lst) (list-set lst 1 new-v))))
> (set-l* '(1 2 3)
        [first-lens 10]
        [second-lens 20])

'(10 20 3)

procedure

(over-l l update-fn structure) → any/c

  l : lens?
  update-fn : (-> any/c any/c)
  structure : any/c
Applies update-fn to the focused value inside structure and returns the updated structure. Equivalent to (set-l l (update-fn (view-l l structure)) structure).

Example:
> (over-l first-lens add1 '(10 20 30))

'(11 20 30)

syntax

(lens-compose l1 l2 ...)

Composes one or more lenses from the outside in: l1 focuses on a part of the structure, the first l2 focuses on a part of what l1 focuses on, and so on. Setting through the composed lens rebuilds every intermediate structure. With a single lens, (lens-compose l1) is l1.

Examples:
> (define nested '((1 2) (3 4)))
> (define first-of-second
    (lens-compose second-lens first-lens))
> (view-l first-of-second nested)

3

> (set-l  first-of-second 99 nested)

'((1 2) (99 4))

5.2 🔗

5.2.1 Common Lenses🔗

 (require freer-lib/lens/common-lenses) package: freer-lib

This module provides ready-made lenses for common Racket data structures, built on top of freer-lib/lens/lens.

procedure

(hash-lens key) → lens?

  key : any/c
Returns a lens that focuses on the value associated with key in an immutable hash table. The get side uses hash-ref, so viewing a missing key raises an error, and the set side uses hash-set, producing a new hash rather than mutating the original.

Examples:
> (define db (hash 'name "Alice" 'age 30))
> (view-l (hash-lens 'name) db)

"Alice"

> (set-l  (hash-lens 'age)  31 db)

'#hash((age . 31) (name . "Alice"))

> (over-l (hash-lens 'age)  add1 db)

'#hash((age . 31) (name . "Alice"))

syntax

(struct-lens id field-id)

Constructs a lens that focuses on field-id within an instance of the struct id. The accessor id-field-id is used for get, and struct-copy is used for set so the original instance is never mutated.

Because the lens refers to the accessor id-field-id by name, the lens must not be bound to that same name.

Examples:
> (struct point (x y) #:transparent)
> (define x-lens (struct-lens point x))
> (define y-lens (struct-lens point y))
> (define p (point 3 7))
> (view-l x-lens p)

3

> (set-l  y-lens 42 p)

(point 3 42)

> (over-l x-lens add1 p)

(point 4 7)

5.3 🔗

5.3.1 Struct Lenses🔗

 (require freer-lib/lens/struct-lens) package: freer-lib

This module provides struct/lens, a drop-in replacement for struct that automatically generates a lens for every declared field, and struct/lens-out, a provide-form that exports the struct together with all its generated lenses.

syntax

(struct/lens name (field ...) option ...)

Defines a struct named name with the given fields, exactly as struct would (any options are passed on to struct), then defines one lens per field. Each lens is named name->field.

Examples:
> (struct/lens person (name age email) #:transparent)
> (define alice (person "Alice" 30 "alice@example.com"))
> (view-l person->name  alice)

"Alice"

> (set-l  person->age   31 alice)

(person "Alice" 31 "alice@example.com")

> (over-l person->email string-upcase alice)

(person "Alice" 30 "ALICE@EXAMPLE.COM")

Lenses compose naturally with lens-compose for working inside nested structures:

Examples:
> (struct/lens team (lead) #:transparent)
> (define t (team alice))
> (define team-lead-name (lens-compose team->lead person->name))
> (view-l team-lead-name t)

"Alice"

> (set-l  team-lead-name "Bob" t)

(team (person "Bob" 30 "alice@example.com"))

syntax

(struct/lens-out struct-type)

A provide form that exports struct-type via struct-out and additionally exports the lens struct-type->field for every field of the struct type, as generated by struct/lens.

Examples:
> (module employees racket/base
    (require freer-lib)
    (provide (struct/lens-out employee))
    (struct/lens employee (name age) #:transparent))
> (require 'employees)
> (view-l employee->age (employee "Carol" 25))

25
