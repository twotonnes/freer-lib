2 Syntactic Forms🔗

To simplify the composition of effectful computations, the library provides standard syntactic sugar.

syntax

(do-m clause ... final-expr)

 
clause = [pattern <- expr]
  | expr
 
  expr : free?
  final-expr : free?
A monadic sequencing macro similar to Haskell’s do-notation. It expands into nested calls to >>=.

  • [pattern <- expr]: Runs the computation expr and matches its result against pattern using match. The variables bound by pattern are in scope for the remaining clauses. If the result does not match pattern, a match error is raised.

  • expr: Runs the computation expr for its effects, ignoring its result, and proceeds to the next clause.

The last form, final-expr, must be a plain expression (not a binding clause); its computation dictates the result of the whole do-m block.

Examples:
; Define a basic "ask" effect
> (struct ask (question))
> (define (ask-user q) (perform (ask q)))
; A computation that asks two questions and combines the results
> (define survey-computation
    (do-m [name <- (ask-user "What is your name?")]
          [age  <- (ask-user "What is your age?")]
          (return (format "~a is ~a years old." name age))))
; Verify the sequencing with a handler
> (run survey-computation
       (lambda (eff k)
         (match eff
           [(ask "What is your name?") (k "Alice")]
           [(ask "What is your age?") (k 30)])))

"Alice is 30 years old."

; Bindings can destructure their result
> (run (do-m [(list a b) <- (return (list 10 20))]
             (return (+ a b)))
       (lambda (eff k) (k eff)))

30
